# the commands a display list compiles, read by tools/gengl.c.
#
# one command to a line: its name, then words.
#   begin          allowed between glBegin and glEnd, any other command in there is a GL_INVALID_OPERATION.
#   custom         recorded by gl_dl_custom_<name> in dlist.c, which says if the command runs now too.
#   <arg>=<count>  a pointer argument, <count> elements are copied when the command is issued. <count> is a C expression of
#                  the other arguments.
# what is not here runs at once while a list is compiled, as the specification has it: the queries, the client state, the
# object names and the vertex arrays.
